// Potongan perbandingan Sync (blocking) vs Async Event Loop (tool/sync_vs_async_demo.dart)
// 1. SINKRON: memblokir thread selama durasi kerja berurutan (~700 ms total)
_blockingWork(350); _blockingWork(350);

// 2. ASINKRON (DART EVENT LOOP):
order.add('1. Kode sinkron (awal)');
Future(() => order.add('4. Future Event Queue (default)'));
Future.delayed(const Duration(milliseconds: 20), () => order.add('5. Timer / Future.delayed'));
scheduleMicrotask(() => order.add('3. Microtask Queue'));
order.add('2. Kode sinkron (akhir)');
// Urutan output: 1 (Sync awal) -> 2 (Sync akhir) -> 3 (Microtask) -> 4 (Event Queue) -> 5 (Timer)
// Paralel: await Future.wait([fetchJadwal(), fetchRekamMedis()]) selesai dalam ~300 ms, bukan 600 ms.

Penjelasan Event Loop: Dart mengeksekusi seluruh instruksi sinkron hingga selesai terlebih dahulu, lalu menguras Microtask Queue (scheduleMicrotask) sebelum memproses antrean Event Queue (Future, I/O, Timer). Pada UI AsyncComparisonScreen (Drawer → Lab Asinkron & Event Loop), tersedia tombol simulasi Loading Indicator, Timeout (TimeoutException), dan Offline (SocketException) yang ditangani try-catch.
