# Program Dart Dasar — Tugas 2 (Bagian Evan)

Folder ini berisi 3 program Dart dasar bertema aplikasi klinik **SehatKu**:

1. `01_class_inheritance_layanan.dart` — Penerapan **Class & Inheritance** (`LayananKlinik` -> `LayananPoli` dan `LayananLaboratorium`).
2. `02_koleksi_daftar_poli.dart` — Penerapan **Koleksi (`List` dan `Map`)** untuk daftar 6 poliklinik, tarif, dan sisa kuota harian.
3. `03_function_null_safety.dart` — Penerapan **Function & Null Safety** (`?`, `??`, `?.`, named parameters) untuk validasi NIK 16 digit, format nomor antrean, dan estimasi biaya BPJS/Umum.

## Cara Menjalankan

```bash
dart run dart_basics/01_class_inheritance_layanan.dart
dart run dart_basics/02_koleksi_daftar_poli.dart
dart run dart_basics/03_function_null_safety.dart
```
